# ระบบจัดการร้านอาหาร (Flask)

เว็บแอปภาษาไทยสำหรับจัดการเมนู โต๊ะ ออเดอร์ หน้าครัว การชำระเงิน ใบเสร็จ และรายงานยอดขาย พัฒนาด้วย Python 3, Flask และ Jinja2

## เริ่มใช้งานบนเครื่อง

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

เปิด `http://127.0.0.1:5000` แล้วเข้าสู่ระบบด้วยบัญชีตัวอย่าง:

- ผู้ดูแลระบบ: `admin` / `admin1234`
- พนักงาน: `staff` / `staff1234`
- ลูกค้า: สมัครสมาชิกผ่านหน้าเว็บ (บัญชีใหม่มี role `customer`)

เปลี่ยนรหัสบัญชีตัวอย่างโดยกำหนด `RMS_ADMIN_PASSWORD` และ `RMS_STAFF_PASSWORD` ก่อนเริ่มแอป การตั้งค่านี้ใช้ตอนสร้างบัญชีครั้งแรกเท่านั้น เปลี่ยนชื่อบัญชีตัวอย่างได้ด้วย `RMS_ADMIN_USER` และ `RMS_STAFF_USER` กำหนด `SECRET_KEY` เป็นค่าสุ่มที่ยาวและคงที่สำหรับทุก deployment

## Deploy บน Vercel

โครงสร้าง `api/index.py`, `vercel.json` และ `requirements.txt` ตั้งค่าให้ Vercel Python Function เรียกแอป Flask แล้ว เชื่อม Git repository กับ Vercel และกำหนด Environment Variables อย่างน้อย:

- `SECRET_KEY`: ค่าสุ่มลับที่คงที่
- `RMS_ADMIN_PASSWORD`: รหัสผู้ดูแลระบบที่ปลอดภัย
- `RMS_STAFF_PASSWORD`: รหัสพนักงานที่ปลอดภัย
- `VERCEL=1` ถูกกำหนดโดยแพลตฟอร์ม

แอปเลือกใช้ `/tmp/restaurant-management-data.json` บน Vercel และคัดลอกชุดตัวอย่างจาก `data.json` ในการเริ่มต้นครั้งแรก การเขียน JSON ใน `/tmp` ใช้ทดสอบหรือสาธิตได้ แต่ Vercel อาจลบไฟล์เมื่อ instance หยุด และ instance หลายตัวไม่ได้แชร์ไฟล์เดียวกัน ดังนั้น JSON ใน `/tmp` **ไม่ใช่พื้นที่เก็บข้อมูลถาวร** สำหรับร้านที่ใช้งานจริง ให้ตั้ง `RMS_DATA_FILE` ไปยัง persistent volume ที่แพลตฟอร์มรองรับ หรือเปลี่ยน backend เป็นฐานข้อมูล/บริการจัดเก็บที่ถาวร ก่อน deploy จริง

## ฟังก์ชันหลัก

- บัญชีและ role `admin`, `staff`, `customer`; รหัสผ่านจัดเก็บแบบ hash และฟอร์ม POST ใช้ CSRF token
- CRUD เมนูและโต๊ะ; ลูกค้าดู ค้นหา และกรองเมนูได้
- เปิดออเดอร์ต่อโต๊ะ เพิ่ม/ลด/ยกเลิกรายการ ย้ายโต๊ะ และปรับสถานะครัวตามเวลา
- คำนวณส่วนลด ค่าบริการ และ VAT พร้อมใบเสร็จพิมพ์ได้
- Dashboard สรุปยอดขายวันนี้ เมนูขายดี และบันทึก audit trail
- ค้นหา/กรอง/เรียง/แบ่งหน้าในรายการเมนูและออเดอร์

## ไฟล์ข้อมูล

`data.json` เป็นชุดข้อมูลตั้งต้นสำหรับการพัฒนา โดยมีเมนูและโต๊ะตัวอย่าง บัญชีผู้ดูแล/พนักงานจะถูกสร้างอัตโนมัติเมื่อเริ่มแอปครั้งแรก และข้อมูลที่แก้ไขจะถูกเขียนกลับไปยังไฟล์ JSON ที่กำหนดด้วย `RMS_DATA_FILE` (ค่าเริ่มต้นในเครื่องคือ `data.json`)
